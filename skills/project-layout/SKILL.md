# Project layout

A new directory or file convention is public API: **api-design** first.
Module files: **app-modules**. Generated server main: **app-server-main**. REST / Cloudflare variant: **app-rest-edge**.

```text
/
├── config/            // the single composition root
│   ├── config.go      // neutral: AppName, DefaultModuleID, Modules()
│   ├── server.go      // !wasm: ServerConfig, ServerDeps, server composition
│   ├── routes.go      // !wasm: Register(r router.Router) — route mount point
│   ├── client.go      // neutral: ClientConfig, ClientDeps, BuildClient() *platformd.Platform
│   ├── css.go         // !wasm: RootCSS() global theme
│   ├── favicon.go     // !wasm: Favicon() favicon.Source (generated by webtyp, with its dependency)
│   ├── lang.json      // the app dictionary (skill langc)
│   └── layouts/       // leaf package for design presets
├── modules/
│   ├── server.go      // !wasm: Server(...) ([]router.OperationModule, error)
│   ├── browser.go     // neutral: Browser(...) ([]platformd.UIModule, error)
│   └── <m>/           // only app-local capabilities (skill app-modules)
├── tests/             // EVERY test of the repo
├── web/
│   ├── client.go      // wasm main(): origin → config.BuildClient
│   ├── server.go      // GENERATED by webtyp (skill app-server-main)
│   └── public/
├── edge/main.go       // optional: Cloudflare Worker (skill app-rest-edge)
└── cmd/migrate/main.go // optional: schema reconciliation, never in the Worker
```

## Invariants

1. **`config/` is one package**, not `app/` + `client/`: server and client share symbols. Types are per layer (`ServerConfig`, `ClientConfig`) — **never `config.Config`** (neutral + `!wasm` files compile together and would collide). Zero-value deps = production; injected doubles = tests.
2. **`config → modules`, never `modules → config`**: `grep -rn "<module-path>/config" modules/` → empty. Shared presets live in `config/layouts/`.
3. **`web/` is `package main` only**: env/origin resolution + a call into `config`. `RootCSS()` lives in `config/css.go` because `sitec` imports it and a `main` is not importable.
4. **Every test in `tests/`** (`package tests`, imports `config`); run with `gotest` (skill **testing**).
5. **Neutral files import only cross-platform types**; SSR-only imports go in `!wasm` files. A neutral file importing SSR breaks the view-test rail.

## Review checklist

- [ ] `config/` imports nothing from the repo's module tree.
- [ ] `web/*.go` only resolve config and call `config`.
- [ ] Backend → `config/routes.go` with one-parameter `Register` (**app-server-main**).
- [ ] `RootCSS()` in `config/css.go`.
- [ ] Module checklist of **app-modules** passes.
- [ ] No `_test.go` outside `tests/`; no `config.Config`.
- [ ] `.build/` in `.gitignore`.
