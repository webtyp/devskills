# The generated server main

**Declaring `var App = appkit.App{…}` in `config/` is the whole requirement** (`server.HasApp`): `webtyp.com/server`
writes `web/server/main.go` = `appkit.Server(config.App, devtools.Server()...)`, `migrate/main.go` = `migrate.App(...)` and `migrate/migrations.go` = `var Migrations = []ddl.Step{...}`.
STATUS (remove this line when IAM_APPKIT_MASTER_PLAN closes): apps not yet on appkit (`iam`, Worker apps) still use
`config/routes.go`, described below. `webtyp.com/server` writes `web/server/main.go` (`// Code generated by https://webtyp.com. DO NOT EDIT.`), compiled to `web/server/server` with no destination tag (`-tags dev` in development). Deploy = `web/server/server` + `web/public`, same tree, started with the working directory at its root (`web/public` is relative to it). In a cloud project (`web/edge/main.go` exists) the Worker is the deploy and the server only runs it locally, composing the same modules.

| Startup log | Condition |
|---|---|
| `External mode: config declares App (appkit), generated main from …` | normal case |
| `External mode: config/routes.go present, generated main from …` | app not yet on appkit |
| `External mode: user-written server main at …` | `web/server/main.go` without the generated header — escape hatch only |
| `Internal mode: no config/routes.go and no server main, checked …` | no backend; assets served from memory |

## What it generates

- `config` defines `RunServer() error` → `main` only calls it.
- Otherwise → `httpd.New(...)` with port 8080, `web/public`, gzip, health, dev TLS, then `config.Register(s.Router())`. None of that is yours to write.

## `AppServer.Routes` / `Register` take exactly one parameter

```go
func Register(r router.Router) // ✅
```

More parameters → the generated call passes `nil` and the app boots with no modules. Dependencies are composed inside `config/`.
